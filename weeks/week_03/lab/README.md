# Lab 3: Value Function Iteration in VS Code

Open the [working folder](starter/) in VS Code and follow its [setup instructions](starter/README.md).

The [notebook](starter/lab_03.ipynb) imports the maze, McCall job search, and continuous saving models. Each model supplies the same [MDP input format](starter/mdp.py) to one [VFI solver](starter/vfi.py), with optional initial values. Run the cells to inspect policies, convergence, runtime, and simulations.
