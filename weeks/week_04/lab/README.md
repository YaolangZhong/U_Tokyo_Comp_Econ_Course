# Working with AI Agents

[Slides](slides/pdf/Working_with_AI_Agents.pdf)

Learn how language models, harnesses, prompts, context, CLI tools, MCP, skills, and project instructions fit together. A simple data-to-chart task connects the concepts throughout the slides.

The practice slide provides a three-row CSV. Create it in a working folder, ask an agent to produce a labelled temperature chart, and inspect the script and saved image. Use an agent with file and terminal access, or attach the CSV to a chat and run the returned code yourself.
