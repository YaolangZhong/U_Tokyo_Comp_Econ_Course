# Homework: Set up a project with Git and Python

Use the two lab decks, [Introduction to Git and GitHub](https://github.com/YaolangZhong/U_Tokyo_Comp_Econ_Course/blob/main/weeks/week_01/lab/slides/pdf/Introduction_to_Git_and_GitHub.pdf) and [Introduction to Python](https://github.com/YaolangZhong/U_Tokyo_Comp_Econ_Course/blob/main/weeks/week_01/lab/slides/pdf/Introduction_to_Python.pdf). Start from the [exercise files](https://github.com/YaolangZhong/U_Tokyo_Comp_Econ_Course/tree/main/weeks/week_01/lab/starter/).

## Git and GitHub

1. Install Git and confirm that VS Code detects it, or check `git --version`.
2. Register for GitHub and complete account verification.
3. Create a folder named `computational-economics`, open it in VS Code, and initialize a Git repository there.
4. Add a README and the supplied `.gitignore`. Inspect and stage the intended files, then make your first commit.
5. Use **Publish to GitHub** in VS Code to create and connect a remote repository. Choose its visibility deliberately and review the files before publishing.
6. Make a second meaningful change, commit, and push. Open the GitHub URL and confirm that both commits appear.

## Python

1. Install a supported Python 3 release and VS Code with Microsoft's Python and Jupyter extensions.
2. Copy `temperature.py` and `temperature.ipynb` from the starter folder into your project.
3. Create a project environment with **Python: Create Environment**, select its interpreter, and run the script.
4. Open the notebook, select the same environment as its kernel, and install `ipykernel` in that environment if prompted. Restart the kernel and run all cells.
5. Verify that both files give **20.0 C = 68.0 F**.
6. Change the input from 20 to 25 degrees Celsius in both files. Predict the new result, then verify **25.0 C = 77.0 F**.
7. Update the README with your Python version, instructions for running the files, both results, and an explanation of the change. Commit and push your work.

## Completion checklist

- GitHub repository URL and two visible commit identifiers/messages.
- A working `.py` file and `.ipynb` notebook that agree on the result.
- A README with the setup, run instructions, results, interpretation, and a check you performed yourself.
- The local environment, caches, credentials, and private data are excluded from the repository.

You may use graphical interfaces. Be ready to explain the changes and verify the output yourself. Keep the repository link and completion evidence ready for the announced submission channel and deadline.
