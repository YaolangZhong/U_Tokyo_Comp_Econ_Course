# Introduction to Git and Python

Two short labs introduce the tools used to organize, run, and share computational work. The emphasis is on understanding each tool's role and checking the result.

- [Introduction to Git — slides](slides/pdf/Introduction_to_Git.pdf): local history, commits, remotes, sharing, and a graphical workflow.
- [Introduction to Python — slides](slides/pdf/Introduction_to_Python.pdf): interpreters, environments, scripts, notebook kernels, IDE basics, and a temperature conversion.
- [Open the first Python notebook in Colab](https://colab.research.google.com/github/YaolangZhong/U_Tokyo_Comp_Econ_Course/blob/main/weeks/week_01/lab/starter/temperature.ipynb): run the guided exercise online and save your own copy.
- [Starter files](starter/): a Python script, notebook, README, and `.gitignore`.
- [Setup homework](../homework/exercises.md): install Python and Git, run both file formats, and connect your project to a GitHub repository.

Readings and direct setup links are included at the end of each deck.
