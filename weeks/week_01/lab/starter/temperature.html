Introduction to Python: Your First Notebook

Convert a temperature, change an input, and check the result. This short exercise introduces code cells, text cells, and the order in which a notebook runs.

Time: about 10–15 minutes. Requirements: Python 3; no extra packages or data files.

Open in Colab · Course website

1. Open and save your copy

In Colab: sign in with your Google account. Choose File → Save a copy in Drive before editing, then connect to a Python runtime. A standard CPU runtime is sufficient. Use the play button beside a code cell, or press Shift+Enter, to run it. Your copy is separate from the course original.

In VS Code: open this notebook and select your Python environment as its kernel. Install notebook support if prompted.

Text cells explain the exercise. Code cells execute Python and display their output underneath. Run the following cells in order.

import sys
print("Python:", sys.version.split()[0])

2. Predict the answer

We convert degrees Celsius, \(C\), to degrees Fahrenheit, \(F\), using

\[F = C \times \frac{9}{5} + 32.\]

For \(C=20\), predict the result before running the code. The input cell below stores the temperature under the name celsius. It does not print anything by itself.

celsius = 20.0

3. Run the calculation

This cell uses the current value of celsius, calculates fahrenheit, and prints both values to one decimal place. The baseline result is 20.0 C = 68.0 F.

fahrenheit = celsius * 9 / 5 + 32
print(f"{celsius:.1f} C = {fahrenheit:.1f} F")

4. Change one input

  1. Change 20.0 to 25.0 in the input cell above.
  2. Predict the new result on paper.
  3. Run the input cell again, then run the calculation cell.
  4. Check that the result is 25.0 C = 77.0 F.

Editing a cell changes the saved code. Running it updates the values held by the runtime. An output displayed below a cell can come from an earlier run.

Try editing the input without running it, then running only the calculation cell. Explain why the result still uses the old input. Finish by running the input and calculation cells in order.

5. Check two familiar temperatures

The following cell checks the same conversion rule at 0 and 100 degrees Celsius. An assert checks whether a statement is true; if it is false, Python reports an error.

assert 0 * 9 / 5 + 32 == 32
assert 100 * 9 / 5 + 32 == 212
print("Both checks passed: 0 C = 32 F and 100 C = 212 F.")

6. Start fresh and reproduce the result

Restart the notebook runtime/kernel to clear stored variables, then run all cells from the top. In Colab, use the Runtime menu to restart the session and run all cells. In VS Code, restart the kernel and choose Run All.

With the input changed to 25, the calculation should still give 77 degrees Fahrenheit. If the result changes after a restart, inspect the cell order and whether all required inputs are in the saved code.

7. Explain and save your work

Edit the text cell below to record your answers. Save your notebook. In Colab, use File → Download → Download .ipynb to take a copy back to your local project folder. Add the completed notebook to your Git repository with your script and README, then commit and push.

Colab lets you practice online. For the setup homework, also run temperature.py and this notebook in your local Python environment and compare their results.
