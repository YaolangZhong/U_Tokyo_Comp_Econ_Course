2. States: names, lists, and positions

A variable names a value; = assigns it. A list stores values in order, starting at index 0. # starts a comment.

Our states are unemployed (U) and employed (E).

# The ordering must be the same in every probability vector and matrix.
states = ["Unemployed", "Employed"]
current_state = 0
print("State names:", states)
print("Current state:", states[current_state])

current_state is an integer used as an index: states[0] is unemployment and states[1] is employment.

3. One transition-probability vector

An unemployed worker finds a job with illustrative probability \(\alpha=0.20\):

\[p_U=(1-\alpha,\alpha)=(0.80,0.20).\]

A decimal number is a float. NumPy provides numerical arrays: import numpy as np gives the package a short name, and np.array(...) converts a list to an array.

import numpy as np

alpha = 0.20
p_unemployed = np.array([1 - alpha, alpha])
print("Next-state probabilities [U, E]:", p_unemployed)
print("Probability of finding a job:", p_unemployed[1])
print("Sum:", p_unemployed.sum())

.sum() is a method belonging to the array. Probabilities must be nonnegative and sum to one.

A Boolean is True or False. np.all(...) checks all entries; np.allclose(...) checks approximate equality. assert stops if a condition is false.

print("All probabilities are nonnegative:", np.all(p_unemployed >= 0))
assert np.all(p_unemployed >= 0)
assert np.allclose(p_unemployed.sum(), 1)

4. From a vector to a transition matrix

An employed worker loses their job with probability \(\delta=0.05\):

\[P=\begin{pmatrix}1-\alpha&\alpha\\\delta&1-\delta\end{pmatrix}.\]

Each inner list forms a row. Rows are today’s state; columns are next month’s, ordered [U, E]. P[0, 1] is the unemployment-to-employment probability.

delta = 0.05
P = np.array([
    [1 - alpha, alpha],
    [delta, 1 - delta]
])
print("Transition matrix:")
print(P)
print("Unemployed to employed:", P[0, 1])
print("Employed to unemployed:", P[1, 0])
print("Row sums:", P.sum(axis=1))
assert np.all(P >= 0)
assert np.allclose(P.sum(axis=1), 1)

axis=1 is a keyword argument telling .sum() to add across each row.

This is a time-homogeneous Markov chain: next-state probabilities depend only on the current state, using the same matrix each month. Its state space is discrete.

5. State versus state-probability vector

A worker’s state is U or E; a probability vector describes uncertainty about it:

\[\mu_0=(0.60,0.40),\qquad \mu_1=\mu_0P.\]

The same vector can represent population shares under the common transition rule. NumPy’s mu0 @ P follows the lecture’s row-vector convention. @ means matrix multiplication; * multiplies entry by entry.

mu0 = np.array([0.60, 0.40])
mu1 = mu0 @ P
print("Initial probabilities:", mu0)
print("Next-month probabilities:", mu1)

# Two ways to end up unemployed next month.
unemployment_next = mu0[0] * P[0, 0] + mu0[1] * P[1, 0]
print("Unemployment, calculated separately:", unemployment_next)
assert np.allclose(mu1[0], unemployment_next)
assert np.allclose(mu1.sum(), 1)

The starting inputs give [0.50, 0.50].

6. Draw one next state

Updating a distribution calculates probabilities; simulation draws an outcome. np.random.default_rng(7) creates a random-number generator with a repeatable seed. rng.choice(2, p=...) draws index 0 or 1.

rng = np.random.default_rng(7)
current_state = 0
next_state = rng.choice(2, p=P[current_state])
print("Today:", states[current_state])
print("One simulated next month:", states[next_state])

P[current_state] selects today’s transition row. A single simulated path need not match population shares.

7. Put the model into a class

A class groups data and operations; an object is one instance.

  • states and P are attributes; simulate is a method.
  • def defines a function. __init__ sets up the object; self refers to it.
  • for ... in range(periods) repeats a block; indentation groups instructions.
  • .append(...) adds to a list; return sends back a result.
  • seed=7 supplies a default argument.
class MarkovProcess:
    def __init__(self, states, P):
        self.states = states
        self.P = np.array(P)
        assert self.P.shape == (len(states), len(states))
        assert np.all(self.P >= 0)
        assert np.allclose(self.P.sum(axis=1), 1)

    def simulate(self, initial_state, periods, seed=7):
        rng = np.random.default_rng(seed)
        state = initial_state
        path = [state]
        for period in range(periods):
            state = rng.choice(len(self.states), p=self.P[state])
            path.append(state)
        return np.array(path)

len(states) counts states; .shape gives array dimensions; == tests equality. The checks validate the transition matrix.

Create an object and call its method below. initial_state=0 starts the worker unemployed with certainty, unlike the uncertain distribution mu0.

employment = MarkovProcess(states, P)
path = employment.simulate(initial_state=0, periods=24, seed=7)
print("State indices from month 0 to month 24:")
print(path)
print("Initial state:", employment.states[path[0]])
print("Final state:", employment.states[path[-1]])

path[-1] selects the last entry.

9. An MDP: state vectors and actions

Use a smaller version of the lecture’s maze:

.  .  G       Start [2, 0]; goal [0, 2]; wall [1, 1]
.  #  .       Actions: up, down, left, right
S  .  .

The state vector [row, column] describes one location; it is not a probability vector. Row 0 is the top. A wall or boundary blocks movement. Each move outside the goal, including entry into it, earns -1; at the goal, stay there and earn 0.

state = np.array([2, 0])
move_up = np.array([-1, 0])
print("Current location:", state)
print("After moving up:", state + move_up)

NumPy adds displacement vectors entry by entry. A dictionary maps names to values: moves["up"] gives the upward displacement.

A policy maps a state to an action. if / else chooses between cases. This policy goes up, then right, avoiding the wall from our start.

def up_then_right(state):
    if state[0] > 0:
        return "up"
    else:
        return "right"

print("Action at the start:", up_then_right(np.array([2, 0])))
print("Action at the top-left corner:", up_then_right(np.array([0, 0])))

10. Build the maze object

step(state, action) returns the next state and reward. simulate(policy, ...) calls the policy and applies step repeatedly.

  • {...} defines a dictionary; np.array_equal compares arrays.
  • and requires both conditions; not reverses a Boolean.
  • state, reward = ... unpacks two results; .copy() keeps a separate array.

Here each state/action pair determines one next cell. MDP transitions can also be random.

class MazeMDP:
    def __init__(self):
        self.goal = np.array([0, 2])
        self.wall = np.array([1, 1])
        self.beta = 0.95
        self.moves = {
            "up": np.array([-1, 0]),
            "down": np.array([1, 0]),
            "left": np.array([0, -1]),
            "right": np.array([0, 1])
        }

    def step(self, state, action):
        if np.array_equal(state, self.goal):
            return state.copy(), 0
        next_state = state + self.moves[action]
        inside = np.all(next_state >= 0) and np.all(next_state < 3)
        if not inside or np.array_equal(next_state, self.wall):
            next_state = state.copy()
        return next_state, -1

    def simulate(self, policy, initial_state, periods):
        state = np.array(initial_state)
        path = [state.copy()]
        rewards = []
        for period in range(periods):
            action = policy(state)
            state, reward = self.step(state, action)
            path.append(state.copy())
            rewards.append(reward)
        return np.array(path), np.array(rewards)

self.beta stores the discount factor \(\beta=0.95\) for later lectures. Pass up_then_right without parentheses so simulate can call the function at each state.

maze = MazeMDP()
maze_path, rewards = maze.simulate(up_then_right, initial_state=[2, 0], periods=6)
print("Locations, including the start:")
print(maze_path)
print("Rewards for the six moves:", rewards)

The goal is reached after four moves; later moves receive zero reward. Six transitions produce seven states, including the start.

def cake_solution():
    # These local definitions leave your CakeMDP and policies unchanged.
    class CakeMDP:
        def __init__(self):
            self.beta = 0.95

        def step(self, state, action):
            assert isinstance(state, (int, np.integer)) and 0 <= state <= 4
            assert isinstance(action, (int, np.integer)) and 0 <= action <= state
            return state - action, np.sqrt(action)

        def simulate(self, policy, initial_state, periods):
            state = initial_state
            path = [state]
            rewards = []
            for period in range(periods):
                action = policy(state)
                state, reward = self.step(state, action)
                path.append(state)
                rewards.append(reward)
            return np.array(path), np.array(rewards)

    def consume_one(state):
        return min(1, state)

    def consume_two(state):
        return min(2, state)

    cake = CakeMDP()
    path_one, rewards_one = cake.simulate(consume_one, 4, periods=5)
    path_two, rewards_two = cake.simulate(consume_two, 4, periods=5)
    print("Consume one: stocks", path_one, "rewards", rewards_one)
    print("Consume two: stocks", path_two, "rewards", rewards_two)
    assert np.array_equal(path_one, [4, 3, 2, 1, 0, 0])
    assert np.allclose(rewards_one, [1, 1, 1, 1, 0])
    assert np.array_equal(path_two, [4, 2, 0, 0, 0, 0])
    assert np.allclose(rewards_two, [np.sqrt(2), np.sqrt(2), 0, 0, 0])
    next_stock, reward = cake.step(4, 2)
    assert next_stock == 2 and np.isclose(reward, np.sqrt(2))
    next_stock, reward = cake.step(0, 0)
    assert next_stock == 0 and reward == 0
    return cake, (path_one, rewards_one), (path_two, rewards_two)
