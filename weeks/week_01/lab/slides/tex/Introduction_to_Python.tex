\begin{frame}{What Is Python?}
\term{Python} is a programming language: a way to write instructions that a computer can carry out. We use it to work with data, perform calculations, and automate tasks.
\par\medskip
\begin{itemize}
\item You write instructions as \term{code}, saved in files that you can edit and share.
\item The \term{Python interpreter} is the software that executes those instructions. Installing Python gives you an interpreter.
\item A \term{script} is a text file containing Python code, usually with the extension \texttt{.py}. Running the script asks the interpreter to execute it.
\end{itemize}
\medskip
Writing code and running code are separate steps: editing a file does not execute it.
\end{frame}

\begin{frame}{Where Do You Write Code?}
An \term{integrated development environment (IDE)} brings together tools for writing, running, and inspecting code in one workspace.
\par\medskip
\begin{itemize}
\item Open a project folder, browse its files, edit code, and see the output when you run it.
\item We use \href{https://code.visualstudio.com/}{\term{VS Code}}. Its Python and Jupyter extensions add support for Python scripts and notebooks.
\item Other options include \href{https://www.jetbrains.com/pycharm/}{PyCharm} and \href{https://cursor.com/}{Cursor}.
\item Select a \term{Python interpreter} for the project. The editor is your workspace; the selected interpreter runs your code.
\end{itemize}
\end{frame}

\begin{frame}{Python Versions and Environments}
\begin{itemize}
\item A \term{Python version} identifies a release of the language and interpreter. Projects may need a particular release to work with their code and tools.
\item A project's \term{environment} is its Python setup: the interpreter it uses and the packages installed for it.
\item A \term{virtual environment} gives a project its own set of installed packages. Changing one project's setup can then leave other projects' setups alone.
\item When creating an environment, choose the Python interpreter it will use. In VS Code, select that environment when running the project.
\end{itemize}
\medskip
To reproduce someone else's work, check both their Python version and their package versions.
\end{frame}

\begin{frame}{What Is a Package?}
A \term{package} provides reusable code written by others, so you can use existing tools without writing everything yourself.
\par\medskip
\begin{itemize}
\item Common tools include \term{NumPy} for numerical arrays, \term{pandas} for data tables, and \term{Matplotlib} for plots.
\item \term{Install} a package into the environment where you will run your code. \term{pip} is a tool for installing Python packages.
\item \term{Import} makes a package's tools available to your code. Installing and importing are separate steps.
\item Packages have versions too. A project's \term{dependencies} are the packages it needs; a file such as \texttt{requirements.txt} can list them and their versions.
\end{itemize}
\end{frame}

\begin{frame}{What Is a Notebook?}
A \term{Jupyter notebook} is a document that combines explanations, executable code, and results. It is saved as an \texttt{.ipynb} file.
\par\medskip
\begin{itemize}
\item \term{Text cells} contain instructions, notes, and equations. \term{Code cells} contain Python instructions that you can run one cell at a time.
\item A \term{kernel} is the running program that executes the cells. For Python, it uses a Python interpreter and its environment.
\item The kernel remembers values between cell runs. Run cells from top to bottom so later cells receive the inputs they need.
\item You can open a notebook in VS Code or use an online notebook service such as Google Colab.
\end{itemize}
\end{frame}

\begin{frame}{Exercise: Open the Notebook in Colab}
\term{Google Colab} lets you edit notebooks in your browser and run Python on a computer provided by Google. You can start this exercise without installing Python locally.
\par\medskip
\href{https://colab.research.google.com/github/YaolangZhong/U_Tokyo_Comp_Econ_Course/blob/main/weeks/week_01/lab/starter/temperature.ipynb}{\textbf{Open the course notebook in Colab}}
\par\medskip
\begin{enumerate}
\item Sign in with your Google account and save your own copy in Drive.
\item Connect to a \term{runtime}: the computer session that runs your notebook. A standard CPU runtime is sufficient.
\item Read the notebook instructions and run its cells in order. The first code cell displays the Python version being used.
\item Complete the exercises: change an input, rerun the relevant cells, and record your observations.
\item Restart the runtime and run all cells. Save your completed notebook and download the \texttt{.ipynb} file to keep with your project.
\end{enumerate}
\end{frame}
