# Archived materials

Alternative slide numbers and copies are preserved in `alternative_slides/`. Previously generated PDFs are in `previous_builds/`; they are historical outputs, not the current weekly handouts. No alternative has been discarded based only on its filename.

`local_cache/` contains old Python caches, retained locally and ignored by Git. The migration manifest records original paths, destinations, and SHA-256 hashes.

`previous_builds/` and `local_cache/` are local-only and ignored by Git. Alternative teaching slides and the migration manifest remain eligible for commits.
