## Course Objectives and Overview *(compulsory)*

In this course, students will study computational methods and tools for economic research — from classical numerical methods to state-of-the-art machine learning techniques — and discuss their theoretical foundations and practical implementations using Python, with the goal of developing the ability to independently apply these tools to their own research projects.

## Course Plan *(compulsory, ~15 subheadings)*

**Week 1:** Introduction to Computational Concepts — round-off and truncation error, conditioning and stability, rates of convergence, Big-O notation, direct vs. iterative methods. Lab: Python and VS Code setup, Python basics.

**Week 2:** Introduction to Markov Decision Processes (MDP) — states, actions, transitions, rewards, and the dynamic programming principle. Lab: Economic modeling with Python; virtual environments and package installation.

**Week 3:** Bellman Equation and Value Function Iteration (VFI) — derivation, contraction mapping, and convergence properties. Lab: Implementing VFI in Python; introduction to Git for version control.

**Week 4:** Policy Function Iteration (PFI) — algorithm structure and comparison with VFI. Lab: Implementing PFI in Python; Git and GitHub workflow.

**Week 5:** Time Iteration (TI) — Euler-equation-based methods and their advantages. Lab: Introduction to LLM-assisted ("vibe") coding for debugging and implementation.

**Week 6:** Endogenous Grid Method (EGM) and Heterogeneous Agent (HA) Models — overview of the Aiyagari framework. Lab: Solving the Aiyagari model.

**Week 7:** Expectation Methods — quadrature, simulation, and unified approaches. Lab: Solving the Krusell-Smith model (Part I).

**Week 8:** Parametrization — approximation methods for value and policy functions. Lab: Solving the Krusell-Smith model (Part II).

**Week 9:** Introduction to Machine Learning for Economics — supervised learning, regression, and neural network basics. Lab: Machine learning workflows with JAX and PyTorch.

**Week 10:** Neural Networks and the Actor-Critic Framework — deep learning architectures and reinforcement learning for economic models. Lab: Implementing a neural network from scratch.

**Weeks 11–13:** Topics to be determined based on student interest and course progress (candidates include: structural model estimation, robustness analysis, advanced HA models). Replication project consultations and presentations.

## Teaching Methods *(compulsory)*

Each class session (approximately 100 minutes) is divided into two parts: a lecture segment (~50 minutes) covering intuition, key concepts, and economic applications with minimal formal proofs; and a lab segment (~50 minutes) of hands-on programming, model solving, and empirical implementation in Python. Students are expected to bring a personal laptop to every class.

---

## Grading Policy *(compulsory)*

Replication Project: 100%.

Each student (or team of 2–3 members) selects a paper in economics or a related quantitative field and replicates its main quantitative results. Teams of N members must replicate N papers. Evaluation focuses on the quality of the replication effort — project design, algorithm implementation, and programming skill — rather than exact numerical reproduction. If published source code exists, students must demonstrate novelty (e.g., alternative algorithm, redesigned pipeline, or robustness checks). All team members receive equal marks.

## Notes on Enrollment, Preparation (Pre-class, Review) *(compulsory)*

**Prerequisites:** Basic familiarity with calculus, linear algebra, and introductory micro/macroeconomics is assumed. No prior programming experience is strictly required, but students with no Python background are strongly encouraged to complete introductory Python tutorials (e.g., *Coding for Economists* or QuantEcon's Python Programming course) before the first class.

**Preparation:** Students should review the lecture slides and any assigned readings before each session. After each lab, students are expected to reproduce and extend the code covered in class as part of their ongoing project work.

---

## Study Advice *(optional)*

Regular hands-on coding practice outside of class is essential. Treat each lab as a starting point, not a finished product. Use large language models (ChatGPT, Claude, etc.) as coding assistants to accelerate debugging and syntax look-up, but always ensure you understand the logic behind generated code. Engaging with the QuantEcon online lectures in parallel with this module will substantially deepen your understanding.
